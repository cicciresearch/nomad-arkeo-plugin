# Support

For assistance with the ARKEO NOMAD Plugin, installation in NOMAD Oasis, or ARKEO data compatibility, contact **CICCI Research**.

**Email:** support@cicciresearch.com

When reporting a problem, please include:

- NOMAD version
- ARKEO NOMAD Plugin version
- Operating system
- Relevant error message

Do not send passwords, authentication tokens, confidential research data, or sensitive customer information.
